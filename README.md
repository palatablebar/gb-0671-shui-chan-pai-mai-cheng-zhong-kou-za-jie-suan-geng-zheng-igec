# 东港水产拍卖结算

给水产市场结算员处理双次称重、扣杂计价、结算更正、冷藏补贴与应付复核。

八个模块：称重采信、货品换算、毛皮配对、扣杂竞价、更正裁决、应付对账、冷藏补贴、结算归档。每个导航页均可重跑同一批数据，隔离行保留编号、原值、行号和原因码。

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
```

浏览器访问 http://localhost:18240 。默认载入现场脏批，包含53条逻辑输入、重复表头、缺列、空值、重复冲突、缺皮重、毛重小于皮重等问题。切换“核验清批”或“旧编码批”后重跑。进入“更正裁决”核对票00001：原应付1168.50CNY，更正后1285.35CNY，已付1168.50CNY，仅待付116.85CNY。

“冷藏补贴”页展示当日固定补贴池（默认600.00CNY，参数见 `sample_data/context.json`，可用 `overrides` 覆盖）的分配对账：早场已核票按票号先分，票00013起因池额不足列待补；票00001的迟到更正只占一次池额，补贴由47.50调整为52.25。每票净应付=待付+入围补贴，池额=已分配+余额。核对无误后点“发布”，发布为单事务，中断自动恢复旧版结果。

API：各模块 `POST /api/<导航英文名>`；完整运行 `POST /api/runs`，JSON参数可用 `dataset` 或 `csv_text`。查询历史 `GET /api/runs`，复核 `POST /api/runs/{run_id}/review`，发布 `POST /api/runs/{run_id}/publish`，均传入当前 `revision`。封存下载只有 `GET /api/export/{run_id}` 一个入口，证据包含补贴分配明细。

同输入和规则摘要生成相同批号，不新增重复记录；复核版本改变后旧版本提交返回409。SQLite保存在命名卷。可使用新卷名称重建演示数据，原卷保留。

定义见 `docs/DATA-DICTIONARY.md`，模块与测试映射见 `docs/DEPTH.md`。源码在 `app/`，业务样例在 `sample_data/`，测试在 `tests/`。不连接实际秤台和支付渠道。

采信页支持上传或粘贴CSV。完整源字节与参数随批次持久化，跨页通过run_id读取同一结果。`POST /api/runs/{run_id}/rerun` 读取该批不可变输入快照重新计算，规则未变时批号不变。切换另一示例则创建或复用另一批次。
